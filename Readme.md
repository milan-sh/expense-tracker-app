# 💰 Expense Tracker App  

**Manage your finances effortlessly - track income and expenses with intuitive controls**  

---

## ✨ Key Features  
- ➕ **Add/Remove Transactions** with one click  
- ✏️ **Edit Entries** dynamically  
- 📱 **Fully Responsive** (Desktop/Tablet/Mobile)  
- 📊 **Visual Balance Summary**  
- 🌈 **Color-Coded Categories** (Income vs Expenses)  

---

## 🚀 Quick Start  

```bash
# Clone the repository
git clone https://github.com/milan-sh/expense-tracker-app.git

# Navigate to project directory
cd expense-tracker-app

# Launch application
open index.html  # macOS
# OR
start index.html # Windows
# OR simply drag index.html to your browser
